# prs-tests

## Releasing to production

A release is a pull request from `main` into `production`, approved once and merged with a merge commit.

[Open the release pull request](https://github.com/mayconmfl/prs-tests/compare/production...main?quick_pull=1&template=release.md&title=Release%3A%20%5BSHIP%5D%20)

Complete the title after `Release: [SHIP] ` with the ticket (or `NO-TICKET`) and a short summary, then fill in the body.
